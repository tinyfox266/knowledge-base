# Test Project for Planning-with-Files Skill

This is a lightweight sandbox project for validating the **planning-with-files** Codex skill.

## How to use it

1. Load the skill in Codex and request a planning workflow against this project.
2. Use this directory as the target so the skill can read/write files here.
3. Confirm that the skill can create/update planning artifacts and reference files inside this project.

## Suggested quick check

- Ask Codex to create a simple plan file (for example `PLAN.md`) and a small TODO list.
- Verify that the outputs appear in this directory.
